= TaviX Studio 0.1.57 — compact Publishing navigation QA

== Scope

UI-only reorganization of existing Publishing controls into four accessible panels: Catalog, Connections, GitHub releases, Tavi Assets / LoopRD. The initial tab is Catalog. Each hidden panel stays mounted, so unsaved local catalog-draft field edits are retained when switching views. No native IPC, registry, pricing contract, authorization or installer behavior changes.
