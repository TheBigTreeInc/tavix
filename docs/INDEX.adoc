== Evidence and change process

A producer consuming this contract should first compare the target Tavi host version, the package manifest's `hostApi` range, and `host.info` feature negotiation. A method implemented by one bundle SDK is not proof the target Tavi host supports it. The standalone TaviX local client is a static developer preview, **not** a host SDK emulator. Never include credentials or trusted host tokens in examples or packages.

Maintain the index, machine-readable contract and two source-backed descriptions in the same development pass as changes to packaging, SDK message shape, available permissions or local-client behavior. Automated regression tests enforce source/documentation alignment for observed names and schema strings; human review still decides whether narrative semantics are accurate. C4 maintenance follows `AGENTS.md`.
