== Reconstruction limitation and mandatory Windows gates

The available historical *full* TaviX 0.1.19 source ZIP contains Companion 0.6.33, whereas the current published GitHub TaviX main catalog contains Companion 0.6.40. TaviX 0.1.20 through 0.1.22 were intentionally **source overlay ZIPs** and do not duplicate previously staged immutable Companion binaries. Consequently a local historical reconstruction cannot pass the complete strict repository/catalog test: 115 of 116 Python tests pass, with the remaining catalog test correctly requiring Companion 0.6.40. Do not replace this with a fake fixture or rewrite historical release content to force a pass. Apply this **overlay** to the actual up-to-date TaviX checkout and run the configured preflight, Python tests, Node test and strict index validation there. The archive is not a full repository bootstrap.

On the actual Windows checkout, inspect the Git status and catalog diff after ZipRunner import. If the existing Companion binary is missing, first restore the exact approved 0.6.40 release from canonical Git, not from an invented package. Stop and do not publish if a protected or historical release hash changes.
