== Changes

* The native masthead displays the actual bundled frontend version. When the source `project.zr` version differs, a warning distinguishes source from the currently running executable.
* The managed Windows launcher checks frontend/Rust source freshness against its executable timestamp. It refuses to launch an older binary after a source update; no process termination or rewrite is attempted.
* Four versioned designer blueprint JSON resources are compiled into the Rust app and no longer rely on launching Python merely to list them. Canonical package inspection is unchanged and still fail-closed with the canonical validator.
* Rust isolates missing Python, empty CLI stdout and invalid JSON into separate safe codes. It never leaks Python stderr, full paths, package contents or credentials.
* The React frontend scopes read-only service failures to the relevant section, retains independent data from successful calls, and includes service codes/version details in the local-only copyable report. Native GitHub and LoopRD remain unimplemented and official publishing disabled.
