= Studio 0.1.54 — native LoopRD publisher adapter and TAVIB detail inspector
:toc:

== Source-owned integration

* `tools/studio-desktop/studio_looprd_adapter.py` implements native-initiated HTTPS/JSON POST to Tavi Assets LoopRD DAPI `/catalog` and `/admin`, bounded and with no ambient proxies or redirect following. Paths are explicit, operator-reviewed and stored alongside the HTTPS hostname in the private Studio profile. The backend contract is `TheBigTreeInc/tavi-assets` `looprd/handler.py` and `looprd/INTEGRATION.adoc` (candidate source, not proof a deployed service exists).
* `assets:read` checks use a native-environment `LOOPRD_ASSETS_READ_TOKEN`; `assets:ingest` stage requires `LOOPRD_ASSETS_INGEST_TOKEN`; `assets:publish` stage inspection/publication uses `LOOPRD_ASSETS_PUBLISH_TOKEN` from the trusted operator process. Token presence is not treated as server-side authorization. No credential is stored in the Studio webview, private publishing settings or source.
* Tauri `studio_publish.rs` sends only strict operator-saved URL components to fixed Python review CLI operations. The webview provides **only an existing reviewed digest**, never a token, arbitrary local file path or arbitrary destination URL. For every mutation the native bridge reopens the approved review and original immutable archive, requires the entire digest, explicit confirmation and a separate receipt selected by OS file picker.
* Staging uses canonical Tavi Assets `unpack_tavia` from a verified locally selected checkout and DAPI `begin/chunk/finalize`. Publication first checks an existing `ready` version and server manifest SHA-256, checks the distinct exact-manifest publish receipt, then invokes `publish` (never a direct DB write). This is registry publication only; no entitlements, Gold, Git source push or automatic store listing.
* `studio_tavib.py` now has `inspect_member()` for bounded, previously validated embedded `.tavib` details from a retained `.tavix` archive. The new Tauri `review_tavib_detail` accepts only a digest and discovered `schematics/*.tavib` member. The UI shows title, origin, pack types, individually required names, prefix minimums (a partial pack may be valid), optional names, author checklist, read-only README text and optional bounded WebP preview before import. HTML/JS from the application is never executed.
* `studio_diagnostics.py` now reports the LoopRD adapter's **source availability**, not an authenticated session, and Publishing owns actual connection checks. No change to separate official publication/entitlement authority.
