== Source boundary

`build_windows.py` uses one dedicated incremental `CARGO_TARGET_DIR=src-tauri/target/studio-managed-build`, distinct from the legacy locked executable path. The first build reuses source but recompiles Rust dependencies under a new target (additional disk and time). On success a new `studio_binary.py` stores a content-hashed immutable executable copy under `target/studio-launch/<version>/<digest-prefix>/` and atomically updates private `current.json`. `run_windows.py` validates version, manifest integrity, SHA-256 and source freshness, and launches only the immutable copy. This does not kill or close prior processes, delete generated builds or adjust ZipRunner's active config; stop remains [] until separate approval.
