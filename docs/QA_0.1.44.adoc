= TaviX Studio 0.1.44 — asset pack grid/list inspector
:toc:

== Scope

Based on the operator's running 0.1.43 native Windows screenshots, the package inspector now defaults to a *Grid* view for each selected pack and offers a reversible *List* toggle in the page header. The resource and file tiles show the original media when available, the full resource/member identifier, and small metadata. Objects/collections/dependencies remain useful text tiles where there is no declared image member. The summary, tabs, 12-item native pagination and adjacent enlarged artwork inspector remain unchanged.

== Safety and performance

Only the existing SHA-256-selected `review_preview` native IPC is used for grid thumbnails; it verifies retained digest-bound original `.tavia`/`.tavix` bytes, safe declared members and constrained image types. No network or local file URLs, unrestricted paths, package execution, HTML embedding, publication authority or backend contract change. Visible tiles are limited to the existing 12-row page with at most three concurrent thumbnail requests and duplicate media member deduplication. On a pack/page/category/view change the grid unmounts and stale promises cannot update it. Failed/unavailable previews remain text-only; the independent full image preview still reports detailed failures. Manual review approval and remote publication are unaffected.

== QA limitations

The delivered ZIP is a ZipRunner incremental overlay (`delete_missing:false`) and lacks some prior historical source modules. Source-only tests cannot establish actual Windows Tauri/React rendering, operator acceptance or exact-candidate ZipRunner post-update QA. No native Rust IPC or TaviX/TAVI Assets wire contract was changed, so the C4 component graph remains stable; the existing pack browser component now additionally renders the bounded grid.
