== Intended result

On a Tavi Android phone with Klondike *not yet installed*, Games should discover Klondike Solitaire 0.1.1 with its application icon, name, offline-game summary and Install option from the official TaviX repository. This must be tested **before** tapping Install. The source ZIP must not perform Git publication or install the game.

== Work performed

The existing TaviX repository stage command was run in a disposable source workspace against the exact package. Immutable release assets and `tavix.repository/v1` metadata were generated and validated. Previously indexed Atrium and Companion releases are unchanged. A clean-device Android installation and public GitHub Pages deployment have not run.

== Mandatory separate operator gates

. Review publisher ownership of legacy `example-org`, the production source URL, and legal distribution rights (the compiled bundle lacks an explicit license). Do not silently change the publisher ID or migrate existing sideloaded users. The catalog `NOASSERTION` value does not waive this review.
. Import candidate into ZipRunner; run preflight, Python tests and strict catalog check on Windows; inspect the exact diff, versions, archive digest and protected paths.
. Approve the exact Git commit and Pages workflow separately. The operator's general interest in a public Store is not by itself a publisher source/licensing approval.
. Verify the published `https://thebigtreeinc.github.io/tavix/tavi.repository.json` contains the exact release revision and that the hosted `ui/index.html` and `ui/icon.png` are accessible.
. **Before installing Klondike** on a phone, open Tavi Store -> Games, refresh and confirm the Klondike card, product details and Install action. If missing, verify Tavi's repository subscription, network, catalog cache and signed-in identity without sideloading.
. Only after catalog discovery passes, test installation consent, Android portrait/landscape touch interactions, Back/close, persistence and updates. Existing Windows sideloads must not be silently transferred to the public source.

== Ownership boundaries

TaviX owns packaged release and static catalog. Tavi owns repository subscriptions, install consent and Store UI. The producer owns source/license provenance. LoopRD owns authentication. No source ZIP here publishes a Git release, charges Gold or enables game completion rewards.
