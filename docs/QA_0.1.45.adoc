= TaviX Studio 0.1.45 — games list, version selector and `.tavia` delivery boundary
:toc:

== User-facing change

*Games & apps* no longer renders one row for every version. One labeled, searchable game/app entry is shown per repository package ID (games first). Selecting an entry shows its explicitly available versions newest first, with a version picker, exact ID, classification and count. The selected version remains associated with that package while navigating other packages; if a source refresh removes it, the newest observed version is shown safely instead. Duplicated identical ID/version manifest entries do not create duplicate choices. No install/preview/approval action is inferred from the selection.

Native source inventory remains read-only and bounded at the existing 250 entries. The viewport becomes a single column at narrow widths and retains keyboard-accessible native version selection. No new Rust command, local filesystem privilege, remote publisher, LoopRD, Wallet or entitlement operation was added. The Studio submission review and artwork inspector are unchanged.

== Cross-project design decision recorded

`TAVIA_CLIENT_ASSET_DELIVERY_045.adoc` documents the agreed per-device shared Tavi cache, independently authorized LoopRD ownership and host SDK model for Tavi/Tavi Assets/LoopRD/Atrium/game owners. This documentation is *target architecture only* and does not assert deployed download/entitlement/cache support. Tarot exact producer resource mapping remains pending.
