= TaviX 0.1.42 — native managed-build path isolation repair
:toc:

== Windows ZipRunner evidence from 0.1.41

ZipRunner 1.2.304.307 applied the 0.1.41 source overlay but its full Python run failed: `Ran 219 tests`, `FAILED (failures=1, skipped=8)`. The failed test was `test_builder_never_terminates_processes_and_does_not_rewrite_old_binary`: a simulated successful subprocess returned build status 0 instead of expected status 1. The cached module-level `BIN` pointed to the original Studio checkout even when the fixture changed `STUDIO`. An old Cargo output could be mistaken for the current one. The actual native build had not yet run because ZipRunner stopped on that test.

== 0.1.42 repair

`tools/studio-desktop/build_windows.py` now computes `build_binary` from active `STUDIO` within `build_native()` and uses the same path for sharing preflight, executable presence/PE header check, immutable `stage_build`, and diagnostics. Keeps the existing dedicated Cargo target directory, immutable launch-copy integrity checks, and no-kill policy.
