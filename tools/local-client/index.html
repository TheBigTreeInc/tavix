Local source status

Git pushing: connection verification is ready; commit, remote staging and push remain unavailable pending a reviewed exact-diff/branch confirmation flow.

Stage a validated asset (separate approval)

Requires a validated local archive, assets:ingest token and a separately approved receipt matching the exact archive SHA-256 and configured LoopRD admin endpoint. Staging never publishes.

Publish or revoke an asset (independent approval)

Requires a distinct verified assets:publish principal, current server record, exact manifest digest and a matching independent publication/revocation receipt. LoopRD audits and authorizes the change.
